## Work completed in this session (all uncommitted)

**Deserializer**
- `DeserializedFunction::bytecodeId` changed from `uint8_t` to `uint32_t`. The narrow type caused wrong closure bodies once a module has more than 256 protos.

**ControlFlowAnalyzer**
- `PartitionBlocks` was split out of `DetermineBasicBlocksInternal`.
- New `ConvergeReturns` undoes Luau's return tail-duplication in if-chains:
  - It groups RETURN blocks by (A, B≥2).
  - It requires the returned registers to be live-in (locals, not temps), at least one non-final copy with work, and a loop-free region between the copies (checked with dominators).
  - It rewrites the earlier RETURN copies into JUMPs to the last copy.
  - `OptimizeGraph` runs it in a loop (up to 64 rounds) with re-partition and re-link.
- Zero-value returns are handled at the AST level instead: `IfExpressionFolder::DropTailReturns` and `MergeTailGuards`.

**SSABuilder**
- `ComputeLiveness` uses a worklist instead of a round-robin fixpoint.
- The worklist is seeded last-block-first, predecessors are rebuilt from successors, and `CheckDecompileDeadline()` is called on each pop.

**ASTLifterConditions `FindMergeBlock`**
- Return exits are ignored for post-dominance unless the merge M is itself a Return or M reaches the return. Reachability is cached in `m_forwardReach`.
- A `fromA` reachability-set prune (`follows`) was added.
- `usesTerminalFold` is disabled when the return block has a JUMP predecessor.
- A diamond whose arms are the literals true/false and whose condition is a comparison or `not` returns the condition directly.

**ASTLifterInlining**
- New helpers: `ValueReader`, `InlinedChainInto`, `RendersAfter`, `RendersInline`, `DominatesMerges`, `DeferIntoCondition`.
- `InliningReordersEffect` changes:
  - a fast-call callee skip;
  - an own-store skip;
  - an `elementAfterDef` check;
  - a `constructorEnd(k)` span skip. A table constructor's contents evaluate contiguously up to its last own store, so the scan jumps past them. This took ANTI_DECOMPILE_SAMPLE from 264s to 3.1s.
- The keyed-store shortcut requires the reader to be in the same block. Without that rule, a loop-hoisted metatable got rebuilt on every iteration.
- LOAD-constant rule: `readThenAssigned` is true only when `AssignedLocal(next) == reg && IsConsumedByPhi(...)`. Expression temps can be written below their sources, so `AssignedLocal` alone gives false positives.

**ASTLifterShared**
- New `IsFastCall` and `AssignedLocal` helpers.

**ASTLifterExpressions**

## Gotchas learned (do not relearn these)

- **Registers are a stack, but expression temps can also be written below their sources.** "Register assigned" does not imply "local variable"; require that the version is consumed by a phi.
- **Luau flushes SETLIST list items before hash items.** "Final SETLIST ends the constructor" is false.
- **A constructor's own contents evaluate contiguously up to its last own store.** The `constructorEnd` skip relies on this.
- **Reordering a table constructor past a field that may raise is a semantic bug.** `elementAfterDef` guards against it.
- **Loop-condition constructors must be deferred into the condition** (`DeferIntoCondition`), or their evaluation order diverges from the original.
- **`ConvergeReturns` can produce nested returns** unless both exemptions hold: `usesTerminalFold` is off when the return block has a JUMP predecessor, and the stop-block dup is skipped when the stop block has a JUMP predecessor.
- **An early-return merge can break the short-circuit fold** unless the M-is-Return and M-reaches-Return exceptions in `FindMergeBlock` apply.
- **CFA, SSA and ASTLifter changes are fragile.** Fixing one loop or branch shape often breaks another. Re-run the Samples replay after touching them.
- **The `Luau::FValue<bool>` flag-enabling loops in `Fission.CLI/src/main.cpp` are load-bearing** for integer constants.
- **Roblox opcode decode is `opcode * 203 mod 256`** (an involution).
